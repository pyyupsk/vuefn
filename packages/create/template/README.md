# My vuefn app

A minimal Vue app with vuefn on Cloudflare Workers.

## Development

```bash
npm install
npm run dev
```

Edit `src/pages/index.vue` to change the home page.

## Commands

```bash
npm run typecheck
npm run build
npm run preview
```

## Deploy

If Wrangler is not signed in, sign in first:

```bash
npx wrangler login
npm run deploy
```
